# Don't Die, Habibi | لا تموت يا حبيبي

A funny Arabic trap platformer: the signs lie, the doors run away, and every trap laughs at you
in Arabic dialects. Plays in the browser, on phone and keyboard.

**Play:** https://aminzikra51-oss.github.io/dont-die-habibi/

لعبة منصّات عربية ساخرة: اللافتات بتكذب، والأبواب بتهرب، وكل فخ بيشمت فيك بلهجة. بتشتغل على الجوال والكمبيوتر.
